## [Unreleased]

### Added
- Initial release of NEVO framework
- Core optimiser with basal ganglia operator selection
- Four standard operators:
  - LevyFlight (exploration)
  - DifferentialEvolution (exploration)
  - ParticleSwarm (exploitation)
  - SpiralOptimisation (exploitation)
- State feature extraction (diversity, improvement rate, convergence)
- Adaptive utility weight learning
- Population-based parallel evaluation
- Comprehensive visualisation tools
- IOHexperimenter integration
- Complete test suite
- Documentation and examples
